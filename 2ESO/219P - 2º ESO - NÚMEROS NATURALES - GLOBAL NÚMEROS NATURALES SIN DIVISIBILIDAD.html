Divise par 3 600 pour obtenir les degrés entiers. Divise le reste par 60 pour obtenir les minutes ; le dernier reste donne les secondes.

Exemple :

20 645″

20 645 : 3 600 = 5°, reste 2 645″
2 645 : 60 = 44′, reste 5″
