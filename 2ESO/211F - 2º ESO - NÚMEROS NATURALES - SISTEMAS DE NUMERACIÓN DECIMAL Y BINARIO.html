1.1 · El sistema decimal

Nuestro sistema habitual es decimal: utiliza diez cifras (0–9) y es posicional (basado en las potencias de 10). El valor de una cifra depende del lugar que ocupa.

Ejemplo: 5 274

Nombre de la cifraUnidades de millarCentenasDecenasUnidades
Cifra5274
Valor posicional10³ = 100010² = 10010¹ = 1010⁰ = 1
Valor de cada cifra5000200704
5 274 = 5·10³ + 2·10² + 7·10¹ + 4·10⁰
= 5·1000 + 2·100 + 7·10 + 4·1   (llamada descomposición polinómica)
= 5 millares + 2 centenas + 7 decenas + 4 unidades

Comprobación de la corrección de la descomposición polinómica decimal (es decir, esta descomposición a qué número decimal corresponde):

... = 5000 + 200 + 70 + 4
= 5 274

1.2 · El sistema binario

El sistema binario utiliza solo dos cifras (0 y 1) y es posicional (basado en las potencias de 2). El valor de una cifra depende del lugar que ocupa. Ejemplo de número binario (en base 2): 101101₂

Nota: En el sistema decimal (en base 10) el número 5274 se puede expresar también como 5274₁₀

Ejemplo: Obtener la descomposición polinómica de 101101₂

Cifra101101
Valor posicional2⁵ = 322⁴ = 162³ = 82² = 42¹ = 22⁰ = 1
Valor de cada cifra3208401
101101₂ = 1·2⁵ + 0·2⁴ + 1·2³ + 1·2² + 0·2¹ + 1·2⁰
= 1·32 + 0·16 + 1·8 + 1·4 + 0·2 + 1·1
= 1·32 + 1·8 + 1·4 + 1·1

Nota: cifra 1 = utilizamos el valor de esa posición · cifra 0 = no utilizamos ese valor

1.3 · Paso de binario a decimal

1.º Coloca las potencias de 2
2.º Haz la descomposición polinómica
3.º Sustituye las potencias por sus valores
4.º Suma

Ejemplo: Convierte 10110₂ a decimal (base 10)

Cifra10110
Valor posicional2⁴ = 162³ = 82² = 42¹ = 22⁰ = 1
Valor de cada cifra160420
10110₂ = 1·2⁴ + 0·2³ + 1·2² + 1·2¹ + 0·2⁰
= 1·16 + 0·8 + 1·4 + 1·2 + 0·1
= 16 + 0 + 4 + 2 + 0
= 22₁₀

1.1 · Le système décimal

Notre système habituel est décimal : il utilise dix chiffres (0–9) et il est positionnel (fondé sur les puissances de 10). La valeur d’un chiffre dépend de la position qu’il occupe.

Exemple : 5 274

Nom du chiffreUnités de millierCentainesDizainesUnités
Chiffre5274
Valeur de position10³ = 100010² = 10010¹ = 1010⁰ = 1
Valeur de chaque chiffre5000200704
5 274 = 5·10³ + 2·10² + 7·10¹ + 4·10⁰
= 5·1000 + 2·100 + 7·10 + 4·1 (appelée décomposition polynomiale)
= 5 milliers + 2 centaines + 7 dizaines + 4 unités

Vérification de la décomposition polynomiale décimale (c’est-à-dire : à quel nombre décimal correspond cette décomposition) :

... = 5000 + 200 + 70 + 4
= 5 274

= 3·10 000 + 0·1000 + 4·100 + 0·10 + 6·1
= 3·10 000 + 4·100 + 6·1

1.2 · Le système binaire

Le système binaire n’utilise que deux chiffres (0 et 1) et il est positionnel (fondé sur les puissances de 2). La valeur d’un chiffre dépend de la position qu’il occupe. Exemple de nombre binaire (en base 2) : 101101₂

Remarque : dans le système décimal (en base 10), le nombre 5274 peut aussi s’écrire 5274₁₀

Exemple : obtenir la décomposition polynomiale de 101101₂

Chiffre101101
Valeur de position2⁵ = 322⁴ = 162³ = 82² = 42¹ = 22⁰ = 1
Valeur de chaque chiffre3208401
101101₂ = 1·2⁵ + 0·2⁴ + 1·2³ + 1·2² + 0·2¹ + 1·2⁰
= 1·32 + 0·16 + 1·8 + 1·4 + 0·2 + 1·1
= 1·32 + 1·8 + 1·4 + 1·1

Remarque : chiffre 1 = on utilise la valeur de cette position · chiffre 0 = on n’utilise pas cette valeur

1.3 · Passage du binaire au décimal

1.º Place les puissances de 2
2.º Fais la décomposition polynomiale
3.º Remplace les puissances par leurs valeurs
4.º Additionne

Exemple : convertis 10110₂ en décimal (base 10)

Chiffre10110
Valeur de position2⁴ = 162³ = 82² = 42¹ = 22⁰ = 1
Valeur de chaque chiffre160420
10110₂ = 1·2⁴ + 0·2³ + 1·2² + 1·2¹ + 0·2⁰
= 1·16 + 0·8 + 1·4 + 1·2 + 0·1
= 16 + 0 + 4 + 2 + 0
= 22₁₀
