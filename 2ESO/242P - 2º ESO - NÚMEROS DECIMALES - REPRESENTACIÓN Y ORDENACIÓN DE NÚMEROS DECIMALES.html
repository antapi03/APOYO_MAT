Quelles valeurs correspondent aux points A, B, C et D sur la droite numérique suivante ?
ما القيم الموافقة للنقاط A وB وC وD على المستقيم العددي الآتي؟
A = B = C = D =
AYUDA:

Identifica dos valores de referencia y cuenta los intervalos entre ellos. Divide la diferencia entre el número de intervalos para saber cuánto vale cada división.

Ejemplo: si de 4,2 a 4,3 hay 10 intervalos, cada división vale (4,3 − 4,2) : 10 = 0,01.
AIDE :

Repère deux valeurs de référence et compte les intervalles. Divise leur différence par le nombre d’intervalles.

Exemple : de 4,2 à 4,3 avec 10 intervalles, une division vaut 0,01.
مساعدة:

حدّد قيمتين مرجعيتين واحسب عدد الفواصل بينهما. اقسم الفرق على عدد الفواصل لمعرفة قيمة كل تدريجة.

مثال: من 4,2 إلى 4,3 مع 10 فواصل، قيمة كل فاصلة 0,01.
SOLUCIÓN:

Primero calculamos cuánto vale cada división de la recta. Entre 3,05 y 3,10 hay 5 intervalos:

(3,10 − 3,05) : 5 = 0,01

Por tanto, cada división vale 0,01. Ahora contamos las divisiones desde una referencia conocida:

A = 3,07  |  B = 3,09  |  C = 3,12  |  D = 3,14

SOLUTION :

Calculons d’abord la valeur de chaque graduation. Entre 3,05 et 3,10, il y a 5 intervalles :

(3,10 − 3,05) : 5 = 0,01

Chaque graduation vaut donc 0,01. Comptons ensuite les graduations à partir d’une valeur de référence connue :

A = 3,07  |  B = 3,09  |  C = 3,12  |  D = 3,14

الحل:

نحسب أولاً قيمة كل تدريجة. بين 3,05 و3,10 توجد 5 فواصل:

(3,10 − 3,05) : 5 = 0,01

إذن قيمة كل تدريجة هي 0,01. بعد ذلك نعدّ التدريجات انطلاقًا من قيمة مرجعية معروفة:

A = 3,07  |  B = 3,09  |  C = 3,12  |  D = 3,14

Para comparar números decimales, compara primero la parte entera. Si coincide, compara las décimas, después las centésimas y, si hace falta, las milésimas. Puedes añadir ceros a la derecha sin cambiar el valor del número.

Ejemplo: Vamos a comparar 5,28, 5,284 y 5,3. Escribimos 5,28 = 5,280 y 5,3 = 5,300. Comparando las cifras del mismo orden obtenemos: 5,280 < 5,284 < 5,300; por tanto, 5,28 < 5,284 < 5,3.

Exemple : Nous allons comparer 5,28, 5,284 et 5,3. Écrivons 5,28 = 5,280 et 5,3 = 5,300. En comparant les chiffres de même rang, on obtient : 5,280 < 5,284 < 5,300 ; donc 5,28 < 5,284 < 5,3.
